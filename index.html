Pong connecté sur ESP32

Un Pong à deux joueurs sur deux microcontrôleurs qui communiquent directement entre eux, sans routeur ni serveur. Le terrain s'étend sur les deux écrans : la balle passe de l'un à l'autre.

  • Communication pair-à-pair en ESP-NOW
  • Architecture maître / esclave pour garder le jeu synchronisé
  • Musique jouée sans bloquer la boucle de jeu
  • C++
  • ESP32
  • ESP-NOW
  • Arduino

Quiz de géographie

Une application pour apprendre les départements, les régions et les préfectures de France. La carte est un fichier SVG chargé par le programme : chaque département se survole, se clique ou se déplace.

  • Six modes de jeu, du puzzle au quiz photo
  • Carte SVG exploitée comme donnée, pas comme image
  • Plus de 2 000 lignes organisées en classes
