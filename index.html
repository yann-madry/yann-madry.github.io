Binôme · 3 jours · juin 2026

Pong connecté sur ESP32

Un Pong à deux joueurs sur deux microcontrôleurs qui communiquent directement entre eux, sans routeur ni serveur. Le terrain s'étend sur les deux écrans : la balle passe de l'un à l'autre.

  • C++
  • ESP32
  • ESP-NOW
  • Arduino
Points techniques
  • Communication pair-à-pair en ESP-NOW : les cartes s'identifient par leur adresse MAC.
  • Architecture maître / esclave : une seule carte calcule la partie et envoie l'état du jeu toutes les 40 ms.
  • Retour automatique à l'écran d'attente si le signal est perdu plus de 2 secondes.
  • Musique jouée sans bloquer la boucle de jeu.

Quiz de géographie

Une application pour apprendre les départements, les régions et les préfectures de France. Chaque département de la carte se survole, se clique ou se déplace.

  • Java
  • Processing
  • SVG
Points techniques
  • Carte SVG chargée par le programme et exploitée comme donnée, pas comme simple image.
  • Six modes de jeu : puzzle, quiz texte, quiz carte, quiz photo, liste à trouver, chaud / froid.
  • Plus de 2 000 lignes organisées en classes, avec une machine à états pour les écrans.
