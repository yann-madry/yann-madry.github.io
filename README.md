# Portfolio de Yann Madry

Code source de mon site personnel : <https://yann-madry.github.io>

Une seule page en HTML et CSS, sans framework ni étape de build. Elle s'adapte au téléphone et suit le thème clair ou sombre du navigateur.

| Fichier | Rôle |
|---|---|
| `index.html` | Contenu : présentation, projets, compétences, parcours, contact |
| `styles.css` | Mise en forme, couleurs des deux thèmes, mise en page responsive |

Pour le voir en local, il suffit d'ouvrir `index.html` dans un navigateur.
