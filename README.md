# Portfolio de Yann Madry

Code source de mon site personnel : <https://yann-madry.github.io>

Une page en HTML, CSS et JavaScript, sans framework ni étape de build.

## Ce qu'il y a dedans

- Un **mini-jeu Pong** jouable en haut de page, dessiné pixel par pixel sur un écran de 128 × 64, la même taille que l'écran OLED de mon [Pong sur ESP32](https://github.com/yann-madry/pong-esp32).
- Des **filtres** pour trier les projets par technologie.
- Un **thème clair ou sombre**, qui suit le réglage du système et se change d'un clic.
- Une mise en page qui s'adapte au téléphone, et des animations désactivées pour les personnes qui ont demandé à réduire les mouvements.

## Organisation

| Fichier | Rôle |
|---|---|
| `index.html` | Contenu : présentation, projets, compétences, parcours, contact |
| `styles.css` | Mise en forme, couleurs des deux thèmes, mise en page responsive |
| `script.js` | Thème, filtres, animations au défilement, mini-jeu Pong |
| `img/` | Carte de France utilisée par la fiche du quiz de géographie |

## Voir le site en local

Ouvrir `index.html` dans un navigateur suffit.
